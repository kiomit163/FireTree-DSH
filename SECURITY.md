# Security Policy

Report security issues privately to the repository owner.

Supported version: 0.1.x.

FireTree-DSH treats repository content, pull requests, evidence, and model output
as untrusted data. Trusted workflows run from the base branch; pull-request code
is parsed as data and is never executed with repository secrets.

Do not include secrets, tokens, or private keys in issues, pull requests, or
evidence bundles.
