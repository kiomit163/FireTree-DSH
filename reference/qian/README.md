## 2. 方法

1. 用 `python-docx` 抽取段落与表格文本（UTF-8）。
2. 对每卷计算 SHA-256，固定语料版本。
3. 对 20 条关键短语做**去空白子串匹配**，记录命中的卷。
4. 结果写入 `sources.json`；本目录 [quotes.md](quotes.md) 是人工可读版。

**能证明**：短语确实存在于该卷。
**不能证明**：整句逐字连续、上下文未被改写、标点与原文一致。引用时按「短引 + 出处」使用。

## 3. 复现

```bash
# 需要 python-docx；DSH 运行时自带
python reference/qian/extract.py --root "D:\Qian" --json reference/qian/sources.json
python reference/qian/extract.py --root "D:\Qian" --check
```

`--check` 会核对四卷 SHA-256 是否与 `sources.json` 一致，并重跑 20 条引文核验；任一失败返回非 0。
