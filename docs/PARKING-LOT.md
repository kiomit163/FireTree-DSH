## 使用方式

- 会上新增：主持人口头确认 → 记录人追加一行 → 不讨论实现。
- 触发条件满足时：在 `docs/DECISIONS.md` 开新决策卡，评估是否进入下一里程碑。
- 每季度清理一次：触发条件消失的条目删除并记录原因。
